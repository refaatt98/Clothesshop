# متجر بَنان 🫶🏼

> لأن التفاصيل تصنع الفرق — قطع يدوية مختارة بعناية، بتفاصيل تضيف لمسة خاصة ليومكِ.

واجهة متجر بَنان: React + TypeScript + Vite + Tailwind CSS v4 + React Router، مع `motion` للحركات و `lucide-react` للأيقونات.

## التشغيل

```bash
npm install
npm run dev
```

بعدها افتحي الرابط اللي بيطلع بالطرفية (عادةً http://localhost:5173).

| الأمر | شو بيعمل |
| --- | --- |
| `npm run dev` | تشغيل الموقع للتطوير |
| `npm run build` | فحص الأنواع وبناء نسخة النشر بمجلد `dist` |
| `npm run preview` | معاينة نسخة النشر محلياً |

يحتاج Node.js 20.19 أو أحدث (الملف `.nvmrc` محدد على 22).

## الصفحات

| الرابط | الصفحة |
| --- | --- |
| `/` | الرئيسية: إطار تطريز بيطرّز حاله، التصنيفات، المختارات، رحلة صنع القطعة، الآراء |
| `/shop` | المتجر مع تصنيفات، بحث، فلترة بالسعر والتوفر، وترتيب |
| `/product/:slug` | صفحة القطعة: معرض، ألوان، تخصيص بمعاينة حية، إضافة للسلة |
| `/cart` | السلة (وفي كمان سلة جانبية من أيقونة السلة) |
| `/checkout` | إتمام الطلب: التوصيل حسب المنطقة، تغليف هدية، دفع عند الاستلام |
| `/order/:id` | تأكيد الطلب + إرسال تفاصيله على واتساب |
| `/custom` | اطلبي قطعتك الخاصة (4 خطوات) |
| `/story` | قصتنا |
| `/contact` | تواصلي معنا + الأسئلة الشائعة |
| `/wishlist` | المفضلة |
| `/admin` | لوحة الإدارة |

السلة والمفضلة محفوظين بمتصفح الزائرة (localStorage)، وكل الباقي بـ Supabase.

## النشر على Netlify

الملف `netlify.toml` جاهز: اربطي المستودع بـ Netlify وهو بيعرف لحاله إنه يشغّل `npm run build` وينشر مجلد `dist`.
كل الروابط (مثل `/shop` أو `/product/jasmine-bag`) بتشتغل مباشرة وحتى بعد تحديث الصفحة.

## هيكل المشروع

```
src/
  pages/        ← صفحة لكل ملف
  components/   ← مكوّنات مشتركة (الهيدر، الفوتر، بطاقة المنتج، الرسومات...)
  data/         ← قيم احتياطية ونصوص ثابتة (القصة، خطوات الصنع)
  lib/api.ts    ← كل جلب وإرسال للبيانات بيمرّ من هون (Supabase)
  pages/admin/  ← صفحات لوحة الإدارة
  types.ts      ← أنواع البيانات
  index.css     ← الألوان والخطوط (tokens) بمكان واحد
```

## تغيير الألوان والخطوط

كل الألوان والخطوط موجودة بأول ملف `src/index.css` داخل `@theme`.
غيّري القيمة مرة وحدة والموقع كله بيتبعها.

## معلومات المتجر

رقم الواتساب، الإنستغرام، أسعار التوصيل وحد التوصيل المجاني بتتعدّل من لوحة الإدارة.

## لوحة الإدارة — `/admin`

افتحي `https://موقعك/admin`:
- **أول مرة:** بيطلعلك «إنشاء حساب الإدارة». اكتبي إيميلك وكلمة سر (8 أحرف أو أكتر). أول حساب بينعمل بيصير حساب المديرة، وبعدها ما حدا بيقدر يعمل حساب.
- إذا Supabase طلب تأكيد الإيميل، افتحي الرابط اللي بيوصلك وارجعي سجّلي دخول.

| الصفحة | شو بتعملي فيها |
| --- | --- |
| لوحة التحكم | مبيعات اليوم وآخر 30 يوم، رسم المبيعات، تنبيهات (آراء، رسائل، مخزون قليل) |
| الطلبات | كل الطلبات، فلترة حسب الحالة، تغيير الحالة، واتساب للزبونة برسالة جاهزة حسب الحالة، طباعة |
| المنتجات | إضافة وتعديل: صور، ألوان، مقاسات، سعر، خصم، مخزون، إخفاء |
| الأقسام | إضافة وتعديل الأقسام وصورها |
| التوصيل | مناطق التوصيل وسعر كل وحدة + الاستلام من البيت + حد التوصيل المجاني |
| أكواد الخصم | نسبة %، مبلغ ₪ أو توصيل مجاني، مع حد أدنى، عدد استخدام وتاريخ انتهاء |
| معرض الأعمال | صور وفيديوهات بتظهر بشريط متحرك بالرئيسية |
| الآراء | موافقة على آراء الزبائن، إضافة آراء (حتى سكرين شوت من واتساب)، اختيار اللي بيظهر بالرئيسية |
| الأسئلة الشائعة | إضافة، تعديل، حذف وترتيب |
| الطلبات الخاصة / الرسائل | طلبات «اطلبي قطعتك» ورسائل «تواصلي معنا» |
| الإعدادات | رقم الواتساب، إنستغرام، النصوص، الشريط العلوي |

لما يوصل طلب جديد وإنتِ فاتحة اللوحة، بيطلع تنبيه بصوت.

## كيف بيوصل الطلب

1. الزبونة بتأكد الطلب ← بينحفظ بقاعدة البيانات ويظهر فوراً بلوحة الإدارة.
2. بعدها بيفتح واتساب لحاله على رقم المتجر برسالة مرتّبة فيها كل التفاصيل (القطع، التخصيص، العنوان، الإجمالي).

## Supabase و Cloudflare

- البيانات كلها بـ Supabase (`src/lib/supabase.ts`، والتفاصيل بـ `supabase/README.md`).
- كل الصور والفيديوهات اللي بترفعيها من اللوحة بتنحفظ على **Cloudflare R2** (bucket: `banan`) وبتنضغط تلقائياً قبل الرفع.
- كل جلب للبيانات بيمرّ من `src/lib/api.ts`.

## المجلد legacy-tareq

فيه كود الموقع القديم اللي كان بهالمستودع، محفوظ للرجوع إليه. ما بيدخل بالبناء، وبتقدري تحذفيه بأي وقت.
