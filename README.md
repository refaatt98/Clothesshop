# أورليه — Ourlet

متجر ملابس تجريبي (واجهة فقط) لدار خياطة خيالية: كل قطعة تُرسم على الورق، تُقصّ باليد، تُرقّم، وتُرفأ مجاناً مدى الحياة.
الموقع كامل بالعربية (RTL)، بألوان فاتحة، وكل الملابس مرسومة كـ«رسومات فنية» (technical flats) بـ SVG مع نسيج قماش حقيقي — بلا صور جاهزة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر (عادةً `http://localhost:5173`).

أوامر أخرى:

```bash
npm run build     # فحص TypeScript + بناء نسخة الإنتاج في dist/
npm run preview   # تشغيل نسخة الإنتاج محلياً
```

## النشر على Netlify

كل الإعدادات جاهزة في `netlify.toml` (أمر البناء، مجلّد النشر، نسخة Node، التحويلات، والهيدرز):

1. ادخل [app.netlify.com](https://app.netlify.com) ← **Add new site** ← **Import an existing project** ← **GitHub**.
2. اختر المستودع `refaatt98/Clothesshop` والفرع الذي تريد نشره.
3. لا تغيّر أي شيء في الإعدادات — Netlify يقرأها من `netlify.toml` تلقائياً — واضغط **Deploy**.

بعدها كل `git push` على الفرع ينشر الموقع تلقائياً، وكل Pull Request يحصل على رابط معاينة خاص.

ما يفعله `netlify.toml`:
- **البناء:** `npm run build` ← ينشر مجلّد `dist` على Node 22.
- **تحويل SPA:** أي مسار يُخدم `index.html` (حالة 200) ليعمل React Router عند فتح أي رابط مباشرة أو عمل Refresh.
- **تحويلات 301 لروابط مألوفة:** `/cart` ← `/rail`، `/products/:slug` ← `/piece/:slug`، `/about` ← `/atelier`، `/faq` ← `/help`، `/blog/*` ← `/journal/*`، `/privacy` ← `/legal/privacy`… وغيرها.
- **الأمان:** CSP (يسمح بخطوط Google وبـ Supabase مستقبلاً)، HSTS، منع الـ iframe، وغيرها.
- **الكاش:** ملفات `/assets/*` تُخزّن سنة كاملة (أسماؤها فيها hash)، و`index.html` دائماً جديد.

## الستاك

- React + TypeScript + Vite
- Tailwind CSS v4
- React Router
- motion (الحركة) و lucide-react (الأيقونات)

## هيكل المشروع

```
src/
  pages/        صفحة لكل ملف (22 صفحة)
  components/   المكوّنات المشتركة (الهيدر، الفوتر، رسومات الملابس، الراف…)
  data/         البيانات الوهمية: القطع، الفصول، الأقمشة، اليوميات، المحلات، الأسئلة
  lib/api.ts    الباب الوحيد للبيانات — كل الدوال async وترجع Promise
  lib/store.tsx حالة المتجر: الراف (السلة)، اللوحة المثبّتة، الإطلالات، العملة
  types.ts      أنواع البيانات
  index.css     كل الألوان والخطوط كـ tokens في مكان واحد (@theme)
```

## ربط Supabase لاحقاً

كل الصفحات تقرأ وتكتب عبر `src/lib/api.ts` فقط. لربط Supabase:
1. أنشئ الجداول بنفس شكل الأنواع في `src/types.ts`.
2. استبدل محتوى الدوال في `api.ts` باستدعاءات `supabase.from(...)` مع إبقاء نفس التواقيع.
3. لا حاجة لتعديل أي صفحة أو مكوّن.

## تغيير الألوان والخطوط

كلها في أعلى `src/index.css` داخل `@theme`:
`--color-paper`, `--color-ink`, `--color-thread` (الأحمر)، `--color-chalk` (الأزرق)… و
`--font-display` (Amiri)، `--font-sans` (IBM Plex Sans Arabic)، `--font-hand` (Aref Ruqaa)، `--font-mono` (Courier Prime).

## الصفحات

| المسار | الصفحة |
| --- | --- |
| `/` | الرئيسية: طاولة القصّ، الراف، من الليفة إلى الحاشية، درج العيّنات، الدفتر المفتوح… |
| `/shop` | المتجر مع فلاتر محفوظة في الرابط (القسم، الفئة، الموسم، اللون، المقاس، السعر، الترتيب) |
| `/shop?dept=women` · `men` · `kids` | الأقسام: ستاتي، رجالي، أطفال (مقاسات الأطفال بالسنوات) |
| `/piece/:slug` | صفحة القطعة: جواز سفر القطعة، مساعد المقاس، حاسبة كلفة اللبسة، ملاحظات من لبسوها |
| `/dressing-table` | طاولة التنسيق: تنسيق إطلالة بالسحب، خلط عشوائي، حفظ، وتعليق الإطلالة كاملة |
| `/rail`, `/checkout`, `/checkout/done` | الراف (السلة)، إتمام الطلب بأربع خطوات، وإيصال الطلب |
| `/chapters`, `/chapters/:slug` | الفصول (المواسم): كل موسم يفتح على قطعه مع فلتر القسم والمقاس |
| `/fabrics` | مكتبة الأقمشة وسلّم الأوزان |
| `/journal`, `/journal/:slug` | اليوميات |
| `/atelier` | المشغل والصنّاع والخط الزمني |
| `/fit-guide`, `/care`, `/shipping`, `/mending`, `/help`, `/contact`, `/visit`, `/legal/:doc` | المساعدة والخدمات — كل النماذج تعمل (بيانات وهمية) |
| `/pinned` | اللوحة المثبّتة والإطلالات المحفوظة |

> الدفع في صفحة إتمام الطلب تجريبي — لا يتم أي دفع حقيقي.

## إضافة موسم أو قطعة

- **موسم جديد:** أضف عنصراً في `src/data/chapters.ts` (مثلاً `title: "شتاء 2026"`).
- **قطعة جديدة:** أضفها في `src/data/products.ts` مع `chapter` (رابط الموسم) و`departments` (`"women"`، `"men"`، `"kids"` — يمكن أكثر من قسم).
